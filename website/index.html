Why VPN Hub?

🔓

Captive Portal Solver

Never struggle with hotel Wi-Fi again. The built-in Management UI allows you to easily scan networks, connect, and authenticate before securing the tunnel.

⚡

Automated Deployment

A single `./deploy.sh` script handles everything. From NAT masquerading on the server to creating a persistent Hotspot and virtual interfaces on the hub.

🛡️

WireGuard Security

Powered by the ultra-fast and modern WireGuard protocol. Your traffic is cryptographically secure and routed perfectly to bypass geographic restrictions.

How It Works

1

Deploy the Home Server

Run the deployment script against an SBC or Linux machine sitting at your house. It automatically configures WireGuard, enables IP forwarding, and sets up NAT masquerade rules.

2

Deploy the Travel Hub

Provision your portable device. It generates a persistent Hotspot (`VPN_Hub_AP`) and a virtual interface (`wlan1`) for scanning networks without dropping connections.

3

Travel & Connect

Connect your phone to the Hub's Hotspot. Go to `http://10.42.0.1`, connect to the Hotel's Wi-Fi, pass the captive portal, and click "Toggle VPN" to secure your connection!
